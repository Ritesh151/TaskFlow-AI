# TaskFlow AI Frontend

This Next.js app is deployment-ready for Vercel.

- App root: `FrontEnd TA-MS/`
- Build: `npm run build`
- Start: `npm run start`
- Required environment variables: `NEXT_PUBLIC_API_URL`, `NEXT_PUBLIC_SITE_URL`

Project-wide setup, Docker, Prisma, Render, and Vercel deployment instructions live in the root [`README.md`](../README.md).
